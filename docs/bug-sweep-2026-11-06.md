# MarketFlow bug sweep, 2026-11-06

Branch `bug-sweep-2026-11-06`, cut from `main` at c048132. It is not merged and not deployed. Render auto-deploys
`main`, so the admin session merges only when Don says OK.

Scope: bugs that give wrong numbers, crash, lose data or break a page. Style nits and type-only `tsc` noise are left
out. Severity: **High** means wrong money or position numbers, lost data or a broken page in daily use. **Med** means
wrong numbers or behavior on a common path. **Low** means an edge case, or latent.

## Checked and found correct

- **Anima gateway:**
  - The token compare hashes both sides and uses `timingSafeEqual`. A missing or short env token turns the gateway off.
  - X-Forwarded-For isn't trusted, and IPv6-mapped addresses fail closed.
  - The path regexes are anchored.
  - The user always comes from env, and every route checks ownership.
  - The plan write is compare-and-set.
- **Signals Lab hit rate and edge:** the sign flip for shorts happens once, in both SQL and JS. Events paging and the cache key are right.
- **Position alerts for shorts:** the cap, warn and breach sides, `pctAway`/`atrAway`, the ET clock and holidays, and the once-per-day keys are all right.
- **Watchlist PATCH flow:** it sends only the edited field. `-100` in the Shares cell sets the side to short. The optimistic update rolls back on error.
- **Discord relay:** batching, resend and recovery on restart are right.

## Gotchas for whoever merges

- `node_modules` in the worktree `E:\Stock-Pattern-Stream-wt-bugsweep` is a **junction** to the main checkout's.
  Remove it with `cmd /c rmdir node_modules` **before** any `git worktree remove`, or git deletes through it.
- **B3 and B5 are forward-only:** rows already written keep their widened `peak_move` and `worst_drawdown` (the
  tracker never shrinks them). Repairing history means a backfill from bars. That is a decision for Don, not done here.
- **B1 changes when user alerts fire:** 1D SMA 10, EMA 50 and similar alerts, crosses and volume confirmations will
  now fire at the real levels. Expect alerts that never fired before, and fewer spurious ones.
